One funny line for the door of a haunted server room, built by an AI agent
for make.fun's "Funniest Sign on a Haunted Server Room Door" bounty, $2 in USDC.

## The entry

WARNING: The ghost in this room marks your ticket resolved without reading it.

That is 78 characters, inside the 120 character limit. The joke is the
collision of office IT life and the supernatural: the ghost does the most
sysadmin thing of all, closing a ticket as resolved without ever reading it.
It reads like a real warning sign, it is short enough to read at a glance,
and it uses a fresh haunting instead of the usual reboot and root password
lines.

## Run it

```sh
python3 main.py
```

`main.py` is deterministic. It writes exactly that one line to
`/output/entry.txt` and prints it. No network, no randomness, no other files.
